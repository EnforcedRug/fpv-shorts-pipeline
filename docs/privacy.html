Privacy Policy — FPV Shorts Pipeline

Last updated: November 8, 2026

FPV Shorts Pipeline is a personal, single-user app built by Ian Kelley for his own YouTube channel, Rug FPV. This policy describes what Google user data the app accesses, how it is used, and how it is stored.

What data the app accesses

The app uses the YouTube Data API and the YouTube Analytics API, with the owner's permission, to:

  • Upload videos as YouTube Shorts to the owner's channel, Rug FPV, including the video file, title, description, and tags.
  • Read the owner's channel and video information, including video IDs, titles, descriptions, and public view, like, and comment counts.
  • Read YouTube Analytics data for the owner's videos, including views, engaged views, likes, comments, average view duration, average view percentage, and subscribers gained.

The app uses only the following Google OAuth scopes: youtube.upload, youtube.readonly, and yt-analytics.readonly.

How the data is used

Google user data is used only to upload the owner's Shorts and to review the performance of those Shorts. It is not used for any other purpose.

How the data is stored and shared

Video files, titles, descriptions, and analytics data are stored locally by the owner for the operation of the pipeline. The app does not share Google user data with any third party, does not sell Google user data, and does not use Google user data for advertising.

Data retention and deletion

OAuth tokens are stored locally by the owner and can be revoked at any time from the owner's Google account security settings. Uploaded videos remain on YouTube until the owner deletes them from YouTube. To request deletion of data held by the app, contact the owner via GitHub at EnforcedRug.

Contact

For questions about this policy, contact the app owner via GitHub at EnforcedRug.

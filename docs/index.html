FPV Shorts Pipeline

FPV Shorts Pipeline is a personal, single-user app built by Ian Kelley for his own YouTube channel, Rug FPV.

It takes an edited FPV drone video, cuts it into short vertical clips, and uploads them as YouTube Shorts to Rug FPV. It also reads basic YouTube Analytics data for those Shorts, such as views, likes, comments, average view duration, and subscribers gained, so the posting schedule can be reviewed.

The app is not offered to other users. It only accesses the YouTube account of its owner.
